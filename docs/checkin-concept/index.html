CHECK-IN CONCEPT / 受付のイメージ

QRはスマホで。
確認と受付は、いつものPCで。

店舗のスマホを受付用の読み取り端末として使い、スタッフはPCで問診を確認します。

受付カウンターでの使い方

お客さんがLINEからQRを提示。スタッフが店舗スマホで読み取り、PCに届いた情報を確認して受付を完了します。

これは提案中の画面イメージです。現在のシステムにスマホからPCへの送信機能はありません。

3つの端末の役割

01 / お客さんのスマホ

QRを提示する

LINEメニューから予約を確認し、問診提出後に参加者のQRを表示します。

02 / 店舗スマホ

QRを読み取る

店舗スタッフがカメラをかざし、受付対象をPCへ送ります。

03 / 店舗PC

確認して受付する

問診と注意事項を確認し、名簿への追加で受付を完了します。

操作を試す

ボタンを押すと、店舗スマホからPCへ届く流れを体験できます。実際のカメラや予約データには接続していません。
