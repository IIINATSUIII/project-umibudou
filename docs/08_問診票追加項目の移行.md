# Issue #13 問診票の追加項目

問診票シートの既存37列（A〜AK）は移動せず、次の列を末尾に追加する。

| 列 | ヘッダー | 内容 |
|---|---|---|
| AL | postalCode | 郵便番号 |
| AM | email | メールアドレス |
| AN | hypertension | 高血圧（true / false） |
| AO | medicalCertificate | 医師の潜水許可書の持参・自己申告（true / false） |

既存環境では問診票シートのAL1:AO1だけに上記ヘッダーを追記する。他シートのヘッダーや既存行を初期化しない。新規環境の初期化処理は追加列に対応済み。

旧データの追加列は空欄のままとする。高血圧は従来の心臓疾患に含まれていたため、過去の回答から個別の有無を推測しない。追加したboolean列の空欄は未回答として読み取り、受付画面でも未回答と表示する。ローカルJSONの旧データも同じ扱い。

新規入力は郵便番号を必須とし、性別は任意（初期値「未回答」）。健康9項目・内服薬・許可書持参は明示的な有無の回答を求める。許可書は本人の自己申告であり、スタッフの確認を示すものではない。

顧客の新規登録には入力メールを保存する。既存の氏名による顧客照合は維持している。メール主キー・電話副キーへの切替と既存顧客の移行は別途対応する。

検証: `node --test scripts/test-questionnaire.cjs`、`npm run typecheck`、`npm run lint`、`npm run build`。画面はモック予約で未入力・形式不正・健康未回答・服薬条件・戻る操作・提出とQR表示を確認する。
