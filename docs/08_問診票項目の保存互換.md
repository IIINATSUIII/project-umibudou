# 問診票③〜⑤の保存形式

- 新規提出は睡眠区分・飲酒2項目・体調・フライト予定・Cカード種別・最終ダイブ時期を必須とする。体調「悪い」は詳細必須（1000文字以内）。認定団体・総本数は任意。
- 睡眠区分は「6時間以上／4時間以上6時間未満／4時間未満」。設計書の「4〜6時間」の境界を明確化した。
- フライトありでも提出可能。画面でガイドへの確認を案内する。
- 新しい sleepCategory / conditionDetails / lastDivePeriod は問診票シートの末尾 AL〜AN 列に追加。既存 A〜AK 列の順序は変更しない。既存シートでは AL1〜AN1 にこの3つのヘッダーのみ追加する（初期化APIで既存シートを再初期化しない）。
- 新規提出の sleepHours は null、lastDiveDate は空文字。過去の数値・年月日はそのまま保持し、QR読取時に旧項目へフォールバックする。区分を数値や実際の日付に変換しない。
- 総本数の未記入は null、0本は数値0。Sheetsの空セルも null として読む。
- 既存記録は引き続き閲覧可能。新規POSTは両APIとも新形式を検証するため、旧形式の外部送信クライアントがある場合は更新が必要。
- API不正値の検証: node --test tests/questionnaire-experience.test.cjs
